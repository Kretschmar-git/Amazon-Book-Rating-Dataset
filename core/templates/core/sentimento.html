Análise de Sentimento

Identificar se comentários de um dataset da Amazon são positivos, negativos ou neutros.

Objetivo

A ideia é usar a linguagem dos comentários para identificar a polaridade da avaliação. Em datasets de e-commerce, textos como “amazing”, “excellent”, “horrible”, “poor” ajudam a classificar o sentimento do usuário.

Pré-processamento dos textos

  • Remover pontuação e caracteres especiais;
  • Converter tudo para minúsculas;
  • Remover stopwords (palavras muito comuns como “the”, “and”, “of”);
  • Tokenizar o texto em palavras;
  • Lematizar palavras para reduzir variações como “reading” e “read” para a base comum.

Vocabulário de sentimentos com VADER

O VADER é uma ferramenta muito útil para textos curtos em inglês, como avaliações de produtos. Ele atribui valores de polaridade e indica se o comentário está positivo, negativo ou neutro. 

from nltk.sentiment import SentimentIntensityAnalyzer
import nltk

nltk.download('vader_lexicon')

sia = SentimentIntensityAnalyzer()
texto = "This product is amazing and works perfectly!"
resultado = sia.polarity_scores(texto)
print(resultado)

# Se compound > 0.05 → positivo
# Se compound < -0.05 → negativo
# Entre -0.05 e 0.05 → neutro
Exemplo de saída: {'neg': 0.0, 'neu': 0.364, 'pos': 0.636, 'compound': 0.8519}.
Como o compound é maior que 0.05, a avaliação é classificada como positiva.

Machine Learning supervisionado

  1. Rotular o dataset com labels: positivo, negativo ou neutro;
  2. Treinar um classificador como Naive Bayes, SVM ou Regressão Logística;
  3. Converter textos em vetores com Bag of Words ou TF-IDF;
  4. Separar treino e teste para avaliar a performance do modelo;
  5. Aplicar o modelo para prever o sentimento de novos comentários.

Fluxo sugerido para implementação

from sklearn.model_selection import train_test_split

Conclusão

A análise de sentimentos é uma etapa essencial para compreender o comportamento dos usuários em plataformas como a Amazon. Enquanto o VADER oferece uma solução simples e eficiente para textos curtos, o aprendizado supervisionado permite criar modelos mais sofisticados para prever a polaridade de comentários novos e automatizar a classificação de grandes volumes de avaliações.
