3) Atributos mais relevantes

  • review/score: estabelece a percepção do usuário sobre o livro;
  • Price: revela relação entre custo, qualidade percebida e demanda;
  • User_id: permite identificar padrões de avaliação por consumidor;
  • review/time: permite analisar evolução temporal das opiniões;
  • Title: mostra quais obras recebem mais atenção;
  • review/text: servem para análise de sentimento e tendências;
  • review/helpfulness: sinaliza o quão útil uma avaliação foi para outros leitores.
